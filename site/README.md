# Сайт ММОСО’Н

Статический сайт проекта: визуальный язык по референсу МХ «КРЯК» — лавандовый
фон, белые «стеклянные» секции-карточки, Montserrat + Raleway, градиентные
подчёркивания, цветные акценты (фиолетовый / коралловый / бирюзовый).

## Состав

```
site/
├── index.html          вся страница, один файл
├── css/styles.css      оформление, адаптив, печать, prefers-reduced-motion
├── js/app.js           появление при скролле, счётчики, меню, лайтбокс
└── assets/fig/         восемь листов из публикации
```

Внешних зависимостей нет, кроме шрифтов Google Fonts. JavaScript — без
библиотек. Сайт работает и без сети на локальном сервере (шрифты заменяются
системными).

## Встраивание в Google Sites

Главный файл для вставки — **`mmoson-google-sites.html`**: в нём всё внутри
(стили, скрипт, восемь иллюстраций как `data:`URI), внешних файлов не требуется.

1. Google Sites → **Вставка → Встроить → Код вставки**.
2. Полностью вставить содержимое `mmoson-google-sites.html`.
3. Растянуть блок по высоте — Google Sites не умеет автоматически менять высоту
   фрейма, поэтому страница скроллится внутри блока.

`mmoson-google-sites-fragment.html` — тот же код без оболочки документа
(`<html>`, `<head>`, `<body>`), стили и скрипт стоят в начале разметки. Нужен,
если при вставке полного документа что-то теряется: некоторые конструкторы
оборачивают вставленный код в свой документ.

Сборка обоих файлов из исходников:

```bash
python3 site/build_standalone.py
```

Скрипт перекодирует иллюстрации в WebP (ширина до 1000 px), встраивает их и
печатает размер. Сейчас: 432 КБ на полный файл, из них 276 КБ — иллюстрации.

Единственная внешняя зависимость — шрифты Google Fonts. Без сети текст
отрисуется системными шрифтами, разметка не поедет.

## Как посмотреть

```bash
cd site
python3 -m http.server 8000    # затем http://localhost:8000
```

Или просто открыть `index.html` в браузере — все пути относительные.

## Разделы страницы

1. **Первый экран** — эмблема, канон в четырёх числах, два действия.
2. **О проекте** — Island Three, точка L1, почему цилиндры не соединены.
3. **Ключевые параметры** — восемь карточек и таблица пакета обшивки.
4. **Инженерные решения** — оболочка, тепло, энергия, транспорт, стыковка, биосфера.
5. **Расчётная верификация** — 243/243, PASS, 0 дефектов, запас 1,53 и честный
   список того, что остаётся открытым.
6. **Иллюстрации** — лайтбокс с восемью листами публикации.
7. **Издание** — 43 документа, 34 раздела, 23 рисунка.
8. **Авторы и лицензия**.

## Публикация

Репозиторий публичный, поэтому сайт можно отдать через GitHub Pages:
Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/site`.
Отдельный workflow не нужен.
