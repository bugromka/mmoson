## Как вернуть файлы

Нужен источник — архив/папка с оригиналами либо репозиторий, где копии ещё живы.
Загрузка из папки делается одной командой:

```bash
python3 tools/upload_images.py <папка с картинками>
```

Скрипт кладёт файлы в `Interregional-cartographic-yacluster/Image` под теми же
именами, что ждёт сайт, сверяет их со списком выше и печатает отчёт.
