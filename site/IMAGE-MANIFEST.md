## Как вернуть файлы

Нужен источник — архив/папка с оригиналами. Загрузка из папки делается одной командой:

```bash
python3 tools/upload_images.py <папка с картинками> --dry-run   # проверка
python3 tools/upload_images.py <папка с картинками>             # загрузка
```

Скрипт кладёт файлы под теми же именами, что ждёт сайт, сверяет их со списком выше и печатает отчёт.
